# 产品主流程文档

本文档描述平台的关键用户流程与系统状态流转。

## 1. 登录流程

1. 用户打开登录页
2. 输入用户名和密码
3. 调用 `/api/auth/login`
4. 登录成功后保存 JWT 与用户信息
5. 跳转到聊天页

失败分支：

- 认证失败，显示错误提示
- 网络失败，允许重试

## 2. 项目与对话流程

1. 用户查看项目列表
2. 选择已有项目或创建新项目
3. 查看项目下历史对话
4. 创建新对话或进入旧对话
5. 加载历史消息

## 3. 阶段一对话流程

1. 用户发送消息
2. 前端调用 `POST /api/conversations/{id}/chat`
3. 后端保存用户消息
4. 后端启动 Manager 普通对话流程
5. 后端通过 WebSocket 推送 `agent_status=running`
6. 后端持续推送 `token`
7. 前端实时展示流式消息
8. 后端推送 `agent_status=done`
9. 完整回复持久化

## 4. 阶段二工作流流程

1. Manager 判断需求已充分明确
2. 调用需求提取器生成结构化需求
3. 调用工作流规划器生成 DAG
4. 前端展示工作流预览
5. 用户确认或修改
6. DAG 编排器执行工作流
7. 各 Agent 推送状态、日志、产出物
8. 工作流结束后生成最终结果

## 5. 状态机建议

### 对话状态

- `idle`
- `sending`
- `streaming`
- `completed`
- `error`

### 工作流状态

- `collecting_requirements`
- `ready_to_plan`
- `awaiting_confirmation`
- `running`
- `paused`
- `failed`
- `completed`

## 6. 错误恢复流程

1. Agent 执行失败
2. 记录日志
3. 按重试次数重试
4. 若仍失败，进入工作流错误处理
5. 回滚到检查点
6. 等待用户决策

## 7. 产出物流程

1. Agent 生成代码、文档或图片
2. 文件写入工作区
3. 后端推送 `artifact`
4. 前端展示预览
5. 用户可下载或导出
